# Protected-chunk ZCU104 board evidence

Each run directory contains the machine-readable summary and UART transcript for one physical ZCU104 run.

- `protected_chunk_bram_17x19`: 1 chunk
- `protected_chunk_bram_256x256`: 48 chunks
- `protected_chunk_bram_512x512`: 192 chunks

`SHA256SUMS.txt` lists SHA-256 hashes for all six evidence files. Per-chunk binary dumps are excluded from this repository.
